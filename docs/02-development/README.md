# Development

This section covers development setup, testing, and contribution guidelines for the Nadi PHP SDK.

## Overview

Nadi PHP is a PHP SDK supporting PHP 8.1+ and Laravel 9.x through 12.x. Development requires
Composer and optionally Docker for OpenTelemetry testing.
